Remonte GLPI PWA V1.0 — version de test
Héberger les fichiers du dossier ensemble sur un hébergement HTTPS autorisé par votre organisation. Aucun serveur applicatif requis. Ouvrir index.html via cette adresse, puis installer le site depuis Edge ou Chrome. Ne pas ouvrir en file://.
Le stockage navigateur est distinct de celui d’Electron. Sauvegarder les anciennes versions et commencer avec un profil PWA vide, sans importer le JSON avant la première récupération. Utiliser le même compte Supabase. Tester avec des fiches fictives uniquement et après autorisation pour les données professionnelles.
Le scanner USB en mode clavier et la saisie manuelle sont conservés. La webcam et les photos utilisent BarcodeDetector si disponible; ZXing n’est pas fourni. La synchronisation reprend le code V1.4.1, non validé en conditions réelles. Connexion à refaire après fermeture. Le cache hors connexion nécessite une première visite réussie. Ne pas effacer les données du site. La synchronisation ne tourne pas lorsque l’application est fermée.

Nouvelle version : resolution explicite des conflits de modification, archive locale des deux versions. Sauvegarder les deux appareils avant mise a jour. Les conflits de doublon ou suppression restent a traiter manuellement. Pas de fusion automatique.
